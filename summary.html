按合计从高到低：ST版V_H最高，其次是ST版V_G，再次是ST版V_C，然后是V_F、QQE基线、做T版、实盘版（148周数字），ST-only最低。每年金额只写美元数，不写收益率百分比。下面5张图的版本颜色和下面各节标题颜色一致；图里金额的正负仍用绿红表示（标题颜色只代表版本，不代表盈亏）。

1. ST版 V_H 合计最高 · 现行ST版

这是现在日页上默认打开的ST版。V_G的逻辑全保留：跳空日（今天开盘价比昨天收盘价高出或低出5个点以上）上午还是用QQE信号，做到11点整强制换成Supertrend趋势的仓位（Supertrend是一条跟着价格走的趋势线，价格在线上面偏多、在线下面偏空）；上午如果是大跳空（10个点以上）就空仓等到11点。下午看今天是往上跳还是往下跳：往上跳的日子继续用QQE，往下跳的日子用Supertrend；Supertrend的单子每30分钟刷新一次，每半小时按当时的价格结算一段、再按同样方向重新进，等于把杠杆刷回原来的水平；不跳空的日子全天用Supertrend。改了三处：第一，Supertrend仓位的止损只在趋势线翻转那根线看——翻转时从开仓起算的累计亏到20%才进窗口（先冻住、不翻仓），没亏到就正常翻仓；第二，出了止损窗口马上按当时Supertrend方向开仓（只限Supertrend仓位）；第三，11点切换时如果上下午策略一样（上跳5到8个点、上午下午都是QQE）就不平仓、接着拿。所以V_H的单数是3,299单，全期比V_G多$8,223,510。

注意：把全期拆成跳空日和非跳空日两部分看时，拆出来的美元会受周内资金路径影响（同一周里先赚的钱会垫高后面单子的本金），所以拆分数字不能单独当成某条腿的利润；标题数字是全期，年度和月度柱子是每周重置再加总的，可以直接加。

注1（总额口径）：每周$100k起，周内逐笔复利，跨周重置，总额=各周利润和；-100口径（单笔最多亏100%）。年度金额四舍五入到整美元，三个年度加起来可能和合计差$1，以合计为准（V_G年度和为$12,119,322，比合计$12,119,321多$1，系四舍五入所致；V_H年度和为$20,342,831，与合计一致）。

注2（最大回撤定义，原文）：build a continuous equity curve from weekly returns — start $100k, each week's return = weekly profit / $100k, equity *= (1 + weekly return) sequentially with NO weekly reset — then max drawdown = largest peak-to-trough percentage decline of that curve over 2024-2026。中文意思：从每周利润算每周收益率（周利润除以10万美元），起点10万美元、按周顺序连乘、不重置，画一条连续权益曲线，最大回撤就是这条曲线从历史高点跌到随后低点的最大百分比跌幅。

注意：最大回撤的算法和总额的算法不一样，只能用来比较几个版本谁的风险相对大，不能直接当成亏了多少钱。总额是每周重置再加总，最大回撤是连续连乘不重置；连续曲线会把每周的大赢利也连乘进去，峰值可以远高于10万美元，所以98%的回撤不等于亏掉98%的本金，只是从那个很高的峰值跌下来的幅度。上面曲线图用的是标准口径（每周重置、累计求和），不是这条连续曲线，两者不要混。

注意：ST腿（V_G/V_C/V_F下午ST、ST-only全天）是30分钟理论口径（每段都按10%杠杆、无价差），实盘按扫单实际杠杆再扣价差。实盘为 VH + QQE 各一半（VH 跑组合桶规则，QQE 跑 0.9 冷冻基线）。实盘曲线为假设资金对半的合成曲线（0.5×VH组合版 + 0.5×QQE 0.9基线，每周重置），不是实际成交。数字来源：V_H行按同一方法由组合版pickle算出，其余行与原summary一致（research/compute_summary_VG.py）；实盘版按上面说明多了一周。2026-06-17那天所有版本都不算在内。
