回测版本总览（2024–2026）

这一页汇总了6个回测版本的年度和合计数字。总额口径一句话：每周10万美元起步，周内每笔按顺序复利，跨周重置回10万美元，总额就是各周利润加起来；单笔最多亏100%。

按合计从高到低：ST版V_C最高，其次是V_F，再次是QQE基线，然后是做T版、实盘版（148周数字），ST-only最低。每年金额只写美元数，不写收益率百分比。

1. QQE基线

只看QQE指标发信号：红柱子变长就偏空做空，蓝柱子变长就偏多做多，信号反了就直接翻仓。单笔亏20%会启动保护：先冻住6根线，期间价格弹回一半就平掉。红波和蓝波里如果整波都涨跌得很慢，翻仓的门槛会放宽一点；长波里灰色的柱子想翻仓要满足更严的长度条件。

2. ST版 V_C 合计最高

平时和QQE基线一样用QQE信号。只有开盘跳空的日子不一样：跳空是指今天开盘价比昨天收盘价高出或低出5个点以上。跳空日上午还是用QQE信号，做到11点整强制换成Supertrend趋势的仓位（Supertrend是一条跟着价格走的趋势线，价格在线上面偏多、在线下面偏空）；上午如果是大跳空（10个点以上）就空仓等到11点。下午看今天是往上跳还是往下跳：往上跳的日子继续用QQE，往下跳的日子用Supertrend；Supertrend的单子每30分钟刷新一次，每半小时按当时的价格结算一段、再按同样方向重新进，等于把杠杆刷回原来的水平。

3. V_F

和ST版V_C很像，区别在跳空日的下午：不管开盘往上跳还是往下跳，下午都直接用QQE信号，不换Supertrend。大跳空（10个点以上）上午同样空仓等到11点，5到8个点的小跳空全天都用QQE、不切换。等于只在上午对大跳空做了空仓处理，其他和QQE基线一样。

4. ST-only

完全不用QQE信号，只看Supertrend这条趋势线：价格在线上面偏多做多、在线下面偏空做空，趋势线一翻转就换仓；每天开盘第一根线就按当时趋势直接进。单子每30分钟刷新一次，每半小时按当时价格结算一段再重新进，把杠杆刷回原来水平；止损保护和日终平仓还在。

5. 做T版

在QQE基线的基础上，价格进入横盘热力区（价格在一个小区间里来回磨、QQE柱子忽长忽短）的时候改做短线来回：区里出现反转信号就反向做一单、赚一点就走，不等大趋势。热力区外还是正常QQE信号。单数比不做T多很多，但来回的单子也把不少利润磨掉了。

6. 实盘版

这是实盘策略的回测数字，不是实盘真实成交的盈亏。和QQE基线一样用QQE信号、20%止损冻住6根线、弹回一半就平，也带灰柱过滤；区别是少了红波蓝波慢涨慢跌时放宽翻仓门槛的那条规则。

注1（总额口径）：每周$100k起，周内逐笔复利，跨周重置，总额=各周利润和；-100口径（单笔最多亏100%）。年度金额四舍五入到整美元，三个年度加起来可能和合计差$1，以合计为准。

注2（最大回撤定义，原文）：build a continuous equity curve from weekly returns — start $100k, each week's return = weekly profit / $100k, equity *= (1 + weekly return) sequentially with NO weekly reset — then max drawdown = largest peak-to-trough percentage decline of that curve over 2024-2026。中文意思：从每周利润算每周收益率（周利润除以10万美元），起点10万美元、按周顺序连乘、不重置，画一条连续权益曲线，最大回撤就是这条曲线从历史高点跌到随后低点的最大百分比跌幅。

注意：最大回撤的算法和总额的算法不一样，只能用来比较几个版本谁的风险相对大，不能直接当成亏了多少钱。总额是每周重置再加总，最大回撤是连续连乘不重置；连续曲线会把每周的大赢利也连乘进去，峰值可以远高于10万美元，所以98%的回撤不等于亏掉98%的本金，只是从那个很高的峰值跌下来的幅度。
